Chức năng Tarif Detail
(frmTarifDetailInput & frmTarifDetailEdit)

Tài liệu hướng dẫn quản lý chi tiết phí Tarif trong hệ thống SMF.

1. Tổng quan

Hai form frmTarifDetailInput và frmTarifDetailEdit dùng để quản lý chi tiết phí (Detail) trong bảng Deatail_Tarif, gắn với Header Tarif (Header_Tarif). Dữ liệu này được sử dụng khi bấm nút Get trên màn hình Inbound (Debit/Credit) để tạo phí tự động.

2. Truy cập chức năng

BướcThao tác
1Vào menu Report → 19. Tarif Header
2Mở form Tarif Header (lưới trên: Header, lưới dưới: Detail)
3Click chọn một Header ở lưới trên
4Chọn menu tương ứng ở thanh menu
MenuForm mở raMục đích
New DetailsfrmTarifDetailInputThêm mới nhiều dòng chi tiết
Edit DetailfrmTarifDetailEditSửa một dòng chi tiết đã có

Lưu ý: Phải chọn Header trước. Nếu chưa chọn Header, menu New Details sẽ bị khóa.

3. frmTarifDetailInput — Thêm chi tiết Tarif mới

Tiêu đề form: New Tarif Details

Thanh trên hiển thị: Header: [Tên] | Customer: [Khách hàng] | Type: Debit/Credit

Quy trình: Nhập thông tin 1 dòng → + Add to List → Lặp lại → Save All

BướcThao tác
1Nhập thông tin từng dòng phí ở vùng Enter Detail Row
2Bấm + Add to List — dòng được thêm vào lưới Pending Details
3Lặp lại để thêm nhiều dòng
4Bấm Save All để ghi tất cả vào database
5Hoặc Close để thoát (có cảnh báo nếu còn dòng chưa lưu)
NútChức năng
+ Add to ListThêm dòng hiện tại vào lưới tạm, xóa trắng form để nhập dòng tiếp
Remove RowXóa dòng đang chọn khỏi lưới tạm (chưa lưu DB)
Save AllLưu toàn bộ lưới tạm vào Deatail_Tarif
CloseĐóng form; hỏi xác nhận nếu còn dòng chưa lưu

4. frmTarifDetailEdit — Sửa chi tiết Tarif

Tiêu đề form: Edit Tarif Detail

BướcThao tác

4Hoặc Cancel để hủy, không lưu

6. Tính toán tự động

Khi thay đổi Qty, Unit Price hoặc VAT%, hệ thống tự động tính:

  • Total Amount = Qty × Unit Price
  • Unit Price Inc VAT = Unit Price × (1 + VAT% / 100)

Hai trường này chỉ đọc (màu xám), không nhập tay.

7. Kiểm tra dữ liệu

  • Item phải chọn hợp lệ từ danh sách
  • Currency không được để trống
  • Khi Save All (form Input): phải có ít nhất 1 dòng trong lưới tạm

9. Liên kết với Inbound (Debit / Credit)

Sau khi tạo xong Header + Detail:

  1. Vào Inbound (Sea hoặc Air Import)
  2. Chọn job inbound
  3. Tab Debit hoặc Credit → chọn Header Tarif tương ứng loại (Debit / Credit)
  4. Bấm Get (Button116 = Debit, Button117 = Credit)

10. Ví dụ thực tế

Tạo Tarif Debit cho khách ABC — phí vận chuyển + phí xếp dỡ:

  1. Tarif Header → New Header: Name = ABC - Debit chuẩn, Customer = ABC Logistics, Type = Debit → Save
  2. Chọn Yes khi hỏi "Do you want to add details now?"
  3. Dòng 1: Item = FRT/KGS/Freight, Currency = USD, Unit = KGS, Qty = 100, Unit Price = 2.5, VAT% = 8, Tigia = 25400 → + Add to List
  4. Dòng 2: Item = THC/BL/Terminal Handling, Currency = USD, Unit = BL, Qty = 1, Unit Price = 150, VAT% = 8, Tigia = 25400 → + Add to List
  5. Save All → 2 dòng lưu vào Deatail_Tarif
  6. Trên Inbound → chọn Tarif "ABC - Debit chuẩn" → Get → 2 dòng debit được tạo

11. Lưu ý quan trọng

  • Type Header (Debit / Credit) phải khớp với tab sử dụng trên Inbound
  • New Details cho phép thêm nhiều dòng một lần; Edit Detail chỉ sửa một dòng
  • Xóa Header trên frmTarifHeader sẽ xóa toàn bộ Detail liên quan
  • Bấm Refresh trên frmTarifHeader để cập nhật lưới sau khi lưu
  • Dữ liệu Detail chưa Save All (form Input) sẽ mất nếu đóng form
  • Nên nhập đầy đủ Tigia trong Tarif Detail để dữ liệu chính xác khi import sang Inbound
